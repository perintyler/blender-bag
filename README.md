# Blender (Barry Pack)

Headless 3D animation authoring, rendering to video, and live scene inspection via Blender.

## Tools

- `blender_status` — check Blender/ffmpeg install status and available render engines
- `blender_render` — render an animation from bpy Python and encode to mp4
- `blender_run_script` — run arbitrary bpy Python in headless Blender
- `blender_scene_info` — summarize a .blend file (objects, keyframes, cameras, materials)
- `blender_encode_frames` — encode a PNG frame sequence into mp4 with ffmpeg

## Skills

- `blender-animation` — animation authoring guidance
- `blender-node-graphs` — node graph workflows
- `blender-physics` — physics simulation
- `blender-scripting` — bpy scripting reference
